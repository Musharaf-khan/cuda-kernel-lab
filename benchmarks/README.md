# benchmarks/

Generated by `scripts/run_all.sh` (or `run_all.ipynb` on Colab). Nothing in here is hand-edited.

| File | Contents |
|---|---|
| `raw/*.txt` | full stdout of every benchmark; the `RESULT|...` lines feed the table |
| `raw/04_gemm_attempts_run*.txt` | SGEMM attempt ladder (each change vs cuBLAS in the same run), 3 runs |
| `raw/04_autotune*.log` | autotuner sweep: every config at n = 256, 1024, 2048, 4096 (median of 3), and the summary |
| `results.md` | master table (`scripts/make_table.py`); repeated runs show the median-time run, and "% of" is the median of per-run ratios |
| `ncu/*_roofline.csv` | Nsight Compute counters per kernel: DRAM bytes, FP32 instructions, duration |
| `ncu/transpose_bank_conflicts.txt` | shared-memory bank-conflict counters for the transpose versions |
| `ncu/sgemm_attempts_sections.txt` | SpeedOfLight, Occupancy, LaunchStats, WarpStateStats and SchedulerStats for every SGEMM attempt + cuBLAS |
| `ncu/sgemm_attempts_metrics.csv` | per-attempt shared-memory bank conflicts, wavefronts, FMA-pipe utilization, warps active, duration |
| `ncu/hgemm_sections.txt` | WMMA kernels vs cuBLAS FP16 kernels: throughput, occupancy, stalls |
| `ncu/attention_sections.txt` | attention v1 vs v2 variants: registers, occupancy, stall reasons |
| `ncu/gemm_v4_v5.ncu-rep` | full Nsight Compute report for GEMM v4 vs v5, from an earlier session (open in the Nsight Compute GUI) |
| `sass/*_instruction_mix.md` | SASS opcode mix per kernel from `cuobjdump -sass` (`scripts/sass_stats.py`): FFMA/HMMA, shared-load widths, spills, whole kernel and hot loop |
| `roofline.png`, `roofline_memory.png`, `roofline.csv` | measured roofline: main chart, zoom on every memory-bound version, and the data (`scripts/roofline.py`) |
| `run_all.log` | full console output of the run |
